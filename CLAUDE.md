# Werkafspraken CreaCo website

Dit is de website van de Crealisatie Coöperatie (CreaCo). Statische HTML zonder build-stap, gehost via GitHub Pages vanaf `main`.

## Workflow

- Elke wijziging gaat via een eigen branch en een pull request naar `main`. Nooit direct naar `main` pushen.
- Laat vóór het openen van de pull request een screenshot zien van het aangepaste deel van de pagina.
- Houd een pull request klein en beschrijf in gewone taal wat er op de site verandert.
- Joris (of een collega) controleert en merget zelf op GitHub.

## Bestanden

- `index.html`: de huidige website
- `schets-v1.html`: eerste schets, niet meer aanpassen
- `overzicht.html`: printoverzicht van alle pagina's
- `assets/`: foto's en logo's; nieuwe afbeeldingen als `.jpg` of `.webp`, maximaal circa 1600 px breed
- `_ds/creaco-design-system/`: huisstijl (lettertypes, kleuren, typografie, spacing); gebruik deze tokens en voeg geen losse kleuren of lettertypes toe

## Schrijfregels

- Schrijf in het Nederlands.
- Gebruik altijd "maakgemeenschap" in plaats van "broedplaats" of "community". Uitzondering: de officiële term "broedplaatsenbeleid".
- Geen gedachtestreepjes midden in een zin.
- Crealisatie Coöperatie, CreaCo en de CC mogen door elkaar gebruikt worden.
- Vermijd typische AI-formuleringen, zoals een alinea afsluiten met een contrastzin ("geen ... maar ...").
- In communicatie richting huurders van De Hoop: "De Hoop bouwt De Nieuwe Hoop".
- Foto's van maakgemeenschap De Hoop zijn van Joke Schut; vermeld "© Foto's: Joke Schut".

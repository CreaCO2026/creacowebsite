# CreaCo website

Schets van de website van de Crealisatie Coöperatie (CreaCo). Statische HTML, zonder build-stap.

## Pagina's

- `index.html` – de websiteschets (versie 2)
- `schets-v1.html` – de eerste versie van de schets
- `overzicht.html` – overzicht van alle pagina's naast elkaar (voor print)

## Mappen

- `assets/` – foto's, logo's en partnerlogo's
- `_ds/creaco-design-system/` – lettertypes en kleur- en typografietokens van de CreaCo-huisstijl

## Bekijken

Open `index.html` in de browser, of zet GitHub Pages aan via Settings › Pages › Deploy from a branch › `main` / root.
